# 故事页宽屏留白与卡纸比例优化

## 目标

优化摄影故事页在 4K 显示器上的横向空间利用率，并在所有分辨率下减少卡纸内衬占比，让实际图片展示面积略微增大，同时保持现有的相框、阴影和响应式结构。

## 方案

- 将故事页媒体容器在宽屏上的最大宽度从当前的 `1280px` 提升到约 `1760px`，并保留约 `48px` 的视口边距，避免 4K 下左右留白过大。
- 将故事相框的卡纸内衬按断点统一收窄：桌面从约 `20–24px` 调整到约 `14–16px`，平板和移动端同步下调。
- 保留相框外边框、阴影、图片比例和照片排序逻辑，仅改变容器宽度与内衬尺寸。
- 不改变故事页内容、图片资源、灯箱行为以及非故事页面样式。

## 验证

- 检查 4K/宽屏、平板和移动端断点下的故事页布局。
- 运行图库测试和完整测试，确保样式改动未影响图库组件行为。
- 运行生产构建，确认 VuePress 构建成功。
