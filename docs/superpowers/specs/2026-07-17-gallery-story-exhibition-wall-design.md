# Story 展墙错位节奏优化设计

状态：设计已确认，待用户审阅文档。

## 背景

当前 Story 页面已经具备暖象牙白展墙、原始画幅相框、博物馆白卡纸和轻微投影，但相框仍然以规则网格为主，整体更像一组 CSS 卡片，和参考图中的摄影展墙在构图节奏、材质层次和留白比例上还有差距。

本次优化采用用户确认的 C 方案“艺术墙面”：在保持照片顺序和整齐秩序的前提下，加入受控的轻微错位，让每个相框像真实展墙上的独立作品；同时强化金属框、卡纸内缩和离墙阴影的三层关系。

本设计文档是对 2026-07-16-gallery-story-refinement-design.md 的 Story 视觉细化补充。它只覆盖 Story 页面，不改变 Gallery 首页、照片数据模型、图库构建流程、灯箱功能或博客/笔记页面。

## 目标

- 让 Story 页面更接近参考图中的当代摄影展墙，而不是规则卡片网格。
- 保留整齐的阅读顺序，同时用小幅垂直错位制造不同画幅的展览节奏。
- 让相框明确呈现“深石墨金属框 → 博物馆白卡纸 → 照片”的层次。
- 保持标题区克制、展签简洁、灯箱交互稳定。
- 在移动端取消错位，确保窄屏阅读和点击区域可靠。

## 非目标

- 不修改 Gallery 首页的故事卡片、首页网格或首页导航。
- 不修改照片 manifest、派生图生成、CDN URL 或 R2 同步逻辑。
- 不新增下载、分享、全屏或其他灯箱功能。
- 不改变已确认的灯箱行为：隐藏右上角关闭按钮、保留边缘箭头、序号位于左上角、保持不循环。
- 不将轻微错位推广到 StoryPhoto、StoryPhotos、StorySplit 等旧布局组件。

## 方案：有秩序的轻微错位

### 展墙与版心

- Story 页面使用 #f5f2ec 暖象牙白背景和极轻的纸张纹理。
- 桌面相册使用宽展墙版心，最大宽度约 1280px，左右保留稳定留白。
- 标题、日期、地点和简介组成左上方独立阅读块，宽度控制在 560–620px，不横跨整个展墙。
- 标题区与相册保持清晰的垂直间距，展墙留白优先于信息密度。

### 网格节奏

- min-width: 960px 时使用 4 列，列间距约 28px，行间距约 42–48px。
- 相框继续使用照片原始宽高比，照片顺序保持不变。
- 相框第一行使用受控偏移：第 1 张 0px、第 2 张 +14px、第 3 张 -6px、第 4 张 +18px。
- 第二行的第 5、6、7 张分别使用 +10px、-4px、+8px 偏移，避免形成机械重复，也不让相框重叠。
- 720–959px 使用 3 列，三列偏移固定为 0px、+8px、-4px；小于 720px 使用 2 列并完全取消错位。
- 偏移只影响视觉位置，不改变 DOM 顺序、键盘顺序、caption 关联或灯箱索引。

## 相框材质

### 三层结构

1. **深石墨金属外框**：使用约 2px 的深石墨细框，允许非常克制的明暗渐变，避免看起来像单一灰色 CSS 线。
2. **博物馆白卡纸**：照片四周保留 18–22px 的白色内缩留白，卡纸颜色与暖象牙白墙面保持轻微色差。
3. **照片层**：保留原始画幅，使用 object-fit: cover，不使用圆角、不做全出血；照片边缘增加极淡的内侧边线，帮助照片从卡纸中脱离。

### 悬浮感

- 相框使用一层贴近边缘的细暗边和一层向右下方扩散的柔和投影，模拟相框离墙几毫米的距离。
- 阴影不能扩散到相邻相框的阅读区域；行间距需要为阴影保留呼吸空间。
- hover 只轻微提高照片亮度，不移动相框、不放大相框、不改变错位关系。

## 标题、展签和返回入口

- 标题左上对齐，使用深灰黑色；日期和地点使用小号低对比度灰色，并保留细分隔线。
- 简介控制在 560–620px，字号保持易读但不过分抢占展墙空间。
- 作品描述直接放在相框下方，仅保留一条约 48px 的细横线和小号灰黑文字。
- 展签不显示序号、不使用卡片底板、不使用圆角、不使用额外阴影。
- 相册末尾保留居中的无文字返回图标，保持 aria-label="返回瞳画"、title="返回瞳画" 和键盘焦点样式。

## 组件与样式边界

- StoryAlbum.vue 继续负责照片顺序、原始比例变量、caption 关联、返回入口和灯箱索引。
- 错位属于 StoryAlbum 的展示层行为，不能写入照片 manifest，也不能影响其他图库组件。
- _gallery.scss 只在 .photo-story-page、.story-album 和 Story 专属灯箱作用域内新增或调整样式。
- 不引入新的图片纹理资源；墙面纹理继续使用低对比度 CSS 背景层，避免增加静态资源和加载依赖。

## 验证方案

- 组件测试确认：照片顺序不变、原始比例变量存在、caption 仍可访问关联、返回入口仍为 icon-only。
- 样式测试确认：桌面错位值受控、移动断点取消错位、金属框/卡纸/双层阴影存在、展签不含序号样式。
- npm test 验证站点组件与 PhotoSwipe 行为。
- npm run gallery:test 验证图库脚本不受影响。
- npm run docs:build 验证 VuePress 生产构建。
- 本地预览检查桌面、平板和移动端：展墙不重叠、错位不破坏阅读顺序、相框层次清晰、灯箱控制保持原约定。

## 验收标准

打开 Story 页面后，应先感受到一面暖象牙白展墙，而不是一组规则卡片。四列相框仍然整齐可读，但垂直位置有轻微差异；深石墨金属框、白卡纸和照片之间有清晰的三层关系；阴影使相框从墙面浮起但不显厚重；标题和简介收在左上方，展签只显示细横线与描述文字；移动端恢复规则两列；灯箱功能和此前确认的关闭、箭头、序号行为不发生变化。
